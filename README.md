# AVA Notebook

基于 AVA 的交互式分析工作台，让分析的证据链可查看、可修改、可分步执行。

## 产品方向

- **无侵入接入**：通过 AVA 的公开接口组合能力，独立管理分析步骤与执行记录。具体接入方式待验证。
- **证据链展示**：关联数据来源、查询或代码、执行结果、图表与结论，展示每一步的输入、输出与依赖。
- **分步执行与修改**：支持在步骤间设置断点、暂停、编辑和重新执行；修改上游后，将受影响的下游结果标记为待更新。
- **Notebook 交互**：参考 Jupyter AI，以纵向单元组织分析过程，将自然语言交互与可编辑的执行步骤结合。
- **视觉风格**：参考 Vercel 的简约风格，以黑白灰、细边框、留白和明确的信息层级呈现内容。

## 本地开发

需要 Node.js 22.13+。将 AVA 与本项目放在同一父目录下：

```text
Documents/
├── AVA/
└── ava-notebook/
```

先在 AVA 中安装依赖并构建，然后在本项目中安装依赖：

```sh
cd ../AVA
npm install
npm run build
cd ../ava-notebook
nvm use
npm install
```

`@antv/ava` 使用 `file:../AVA`，默认通过符号链接指向本地 AVA。修改 AVA 源码后，需在 AVA 中重新运行 `npm run build`，本项目才能使用更新后的构建产物。
