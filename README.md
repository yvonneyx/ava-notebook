# AVA Notebook

**用一句话分析 CSV，在 Notebook 中看清每一步。**

基于 [AVA](https://github.com/antvis/ava) 的数据分析工作台。上传 CSV，用自然语言提问，AVA 自动探索数据、执行 SQL，Notebook 将过程整理成可回看、可修改的分析笔记。

[在线体验](https://ava-notebook.vercel.app) · 内置「各地区销售额对比」和「2 月业绩下滑归因」两个案例。目前线上可浏览案例、编辑草稿，尚未接入查询执行。

## 在笔记中查看和修改分析

从分析步骤到 SQL、数据、图表和结论，在一份笔记中查看完整过程。支持暂停执行、修改 SQL，再从某一步创建分支继续分析。

![AVA Notebook 分析笔记](https://mdn.alipayobjects.com/huamei_aphk1k/afts/img/A*NypWQongLZkAAAAAU0AAAAgAegfkAQ/original)

## 在图谱中追溯结论的依据

图谱把数据源、分析步骤、SQL、查询结果和结论连接起来，方便检查每个结论来自哪里。
